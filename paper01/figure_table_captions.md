# Paper 01 — figure and table captions (suggested wording)

All figures were generated by `R/figures_paper01.R` and all tables by
`R/tables_paper01.R` from the study outputs in `paper01/output/` (each with a
JSON provenance sidecar). Edit captions freely while writing;
edit numbers only by re-running the scripts.

## Figures

**Fig01 — Methods flow.** The analysis pipeline from daily records to the
frozen confirmatory contrasts. Every box is a script stage in `R/`; the
leakage-discipline banner states the split rule that no threshold, screen,
standardisation or fit touches a test year before scoring.

**Fig02 — Study sample (panel a).** The 257 read CAMELS-IND catchments, by
screen stage: 231 pass the completeness screens, 218 pass the >= 8-event
screen for the confirmatory target, and 136 additionally pass the
recession-quality screen (>= 20 censored segments of >= 10 days). 111 of the
storage-family catchments borrow basin-median parameters. Source:
`output/p1_sample_report.csv`, `output/p1_storage_params.csv`.

**Fig03 — Lead-time skill curves (panel b; centrepiece).** Median Brier
skill score vs climatology per family and lead. Persistence carries the most
skill at every lead; all families collapse between the 1- and 3-month leads.
Source: `output/p1_bss.csv`.

**Fig04 — Confirmatory paired deltas (panel c).** Per-gauge paired Brier
deltas of the confirmatory family `storage + indices` against the frozen
per-gauge best-of memory baseline, on identical held-out months (2011-2020).
Red dot = median. Source: `output/p1_paired.csv`.

**Fig05 — The mechanism (panel d).** The ledger-verified fluid storage state
S(t) for catchment 13004 alongside observed flow and precipitation: with a
recession constant of about 8.5 days the state is a smoothed mirror of the
flow record, which is the mechanism behind the confirmatory null.

**Fig06 — Storage landscape (panel e).** Fitted recession constants and
storage scales across the sample (12 largest basins; colour = baseflow
index). Indian catchments concentrate at short recession constants.
Source: `output/p1_storage_params.csv`.

**Fig07 — Reliability (panel f).** Pooled reliability curves for the
hydrological-drought target at the 3-month lead. Source:
`output/p1_predictions.csv` (regenerable by `R/study_p1.R`).

**Fig08 — The memory wall.** (a) Fitted recession constants against the
constant a lead would require; (b) share of the state's memory retained at
each lead. Source: `output/p1_storage_params.csv`.

**Fig09 — Skill against memory.** Per-gauge skill gain of the storage family
over lagged indices at the frozen 3-month lead, against that gauge's own
recession constant. Source: `output/p1_bss_paired.csv`,
`output/p1_storage_params.csv`.

**Fig10 — Equivalence.** Median paired difference and 90 % bootstrap interval
per lead, against the declared $\pm 0.005$ Brier harm band. Source:
`output/p1_equivalence.csv`.

**Fig11 — Summary grid.** Six panels: sample funnel, memory budget, share of
gauges with useful memory, skill decay, paired differences and equivalence.

**Fig12 — Basin grid.** The same decay curve in the twelve largest basins,
lagged indices against the storage family.

**Fig13 — Attribute correlations.** Spearman rho of each catchment attribute
with forecast skill and with the storage gain, at the three-month lead.

**Fig14 — Skill against attributes.** Per-gauge skill versus six attributes.

**Fig15 — Basin skill.** Median skill of the lagged indices by river basin.
