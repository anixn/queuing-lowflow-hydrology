# 02 — Search strategy

## Objective

Search for evidence that supports or disproves the proposed strengthening directions, especially conservation-constrained backlog inference, identification, recovery distributions and coupled state-space drought models.

## Sources actually used

- OpenAlex API: reproducible title/abstract counts and metadata.
- Crossref API: attempted bibliographic queries; all seven requests returned HTTP 429, so no Crossref records were exported.
- Web search: supplementary discovery only; result counts were not reported by the interface.
- SSRN full text: Acosta et al. (2026), 36-page preprint downloaded and text-extracted.
- OSTI metadata/abstract: Zhao et al. (2018).
- Existing repository Phase-A WoS/Scopus exports and citation trace.

## Query families

1. Exact topic: drought + queueing/backlog/unmet demand.
2. Mechanism: storage + demand + state space + conservation.
3. Method: first passage + recovery + non-stationary queue.
4. Identification: queue parameter/state estimation + identifiability.
5. Attribution: demand/supply + water scarcity + decomposition.
6. Adjacent field: coupled human–water drought + data assimilation.
7. Failure terms: zero flow, intermittent service, non-identifiability, null result.

## Inclusion criteria

- Directly relevant to drought backlog, storage–demand coupling, queue dynamics, identification, recovery or validation.
- Identifiable scholarly record or authoritative technical source.
- Methodological detail sufficient to compare with the proposed contribution.

## Exclusion criteria

- Distribution-tail false positives.
- Healthcare, transport, telecom or production queues without a water-system mechanism.
- Operational allocation without a physical deficit state, unless needed as closest prior art.
- Records that cannot be identified or retrieved.

## Screening rule

Retain a record if it could change a candidate's novelty assessment or provide a stronger baseline. Record counter-evidence explicitly. A record is “gap-changing” only if it contains all four elements of the frozen sentence.

## Limits

This is a targeted exploratory search. It is not PRISMA-compliant, not comprehensive, and not a substitute for a pre-submission database refresh.
