# Real-data comparison figure

`real_data_comparison.png` and `real_data_comparison.svg` are generated by `../../../src/P02/make_comparison_figure.py` from:

- `../data/real_data_comparison_metrics.csv`;
- `../data/real_data_reliability.csv`.

Run after `src/P02/real_data_comparison.py`:

```powershell
python src/P02/make_comparison_figure.py
```

The figure shows the primary q*=6 SMA comparison: 98 held-out months and four drought months per gauge. Hatched SPI/SPEI bars are external 1981–2020-standardized benchmarks, not strict held-out baselines. Queue outputs are **illustrative, under the stated assumptions**. Same-month observed flow makes the analysis retrospective; the figure makes no forecast claim.
