# Real-data comparison figure

`real_data_comparison.png` and `real_data_comparison.svg` are generated by `../../../src/P02/make_comparison_figure.py` from:

- `../data/real_data_comparison_monthly.csv`;
- `../data/real_data_comparison_predictions.csv`;
- `../data/real_data_comparison_metrics.csv`;
- `../data/real_data_reliability.csv`.

Run after `src/P02/real_data_comparison.py`:

```powershell
python src/P02/make_comparison_figure.py
```

The six panels show the observed SMA target, uncalibrated model-predicted probabilities with observed drought months shaded, Brier skill and reliability for gauges 4026 and 4064. Each gauge has 98 held-out months and four drought months; reliability bins are sparse and descriptive.

The supplied SMA target and published SPI/SPEI use an external 1981–2020 reference period that overlaps the nominal test years, so target construction and those benchmarks are not strictly held-out. Same-month observed flow makes the analysis retrospective; the figure makes no forecast claim. Queue outputs are **illustrative, under the stated assumptions**.
