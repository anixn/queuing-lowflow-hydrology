# Generated real-data comparison outputs

Every CSV in this directory is generated by `../../../../src/P02/real_data_comparison.py` and must not be hand-edited.

| File | Content |
|---|---|
| `real_data_queue_daily.csv` | Daily λ, μ, end-of-day queue probabilities and imputation provenance |
| `real_data_comparison_monthly.csv` | Monthly targets, SSI/SPI/SPEI and queue predictors |
| `real_data_comparison_predictions.csv` | Training/test predictions for every model and q* |
| `real_data_comparison_metrics.csv` | Held-out Brier, skill, AUC, log loss, calibration and decision fields |
| `real_data_reliability.csv` | Fixed-bin held-out reliability summaries |
| `real_data_comparison_events.csv` | SMA events and retrospective onset offsets |
| `real_data_bootstrap.csv` | Paired year-block bootstrap for the primary Brier difference |
| `real_data_imputation_sensitivity.csv` | Causal-fill and imputation-exclusion sensitivities |
| `real_data_model_parameters.csv` | Logistic coefficients, standardization and fit diagnostics |
| `real_data_source_audit.csv` | Flow coverage, gaps, zeros and imputation audit |
| `real_data_target_audit.csv` | Expected/available months and SMA event counts |
| `real_data_run_metadata.json` | Settings, solver diagnostics and source hashes |

The confirmatory result is null. Queue outputs are **illustrative, under the stated assumptions**; the comparison is retrospective and makes no forecast claim. Supplied SMA and published SPI/SPEI use an external 1981–2020 reference period, so target construction and those benchmarks are not strictly held-out.
