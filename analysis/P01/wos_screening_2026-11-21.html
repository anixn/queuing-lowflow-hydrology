P01 — WoS record-level screen

1. Purpose

Screen the four Web of Science sets whose hit counts were captured but whose record cards would not render in the earlier session (../../paper1/literature_audit.md:57-63). This was the last database screen before the gap sentence could be frozen (../../AGENTS.md:174-182).

2. Access and method (21 November 2026)

  • Institutional sign-in was not required. The session browser was IP-entitled (splash frame “Register to personalize your Web of Science experience”, IP 14.139.122.139); the Clarivate sign-in page was reached but no profile was signed in, and search, export and record metadata all worked without a profile.
  • The WoS interface changed since 20 November: the Advanced Search Query Builder textarea now accepts and requires the TS=(...) field tag; the bare Boolean string now returns “Invalid field tag”. All four sets were run as TS=(<bare Boolean>) in the Query Builder.
  • The earlier record-card renderer stall (loading-cover state) was bypassed entirely: each result set was exported with Export → Excel, record content “Author, Title, Source, Abstract”. S5 (66 hits) exceeded the page size of 50, so page 1 (records 1–50) and page 2 (records 51–66) were exported separately; the range option “Records from 1 to 66” did not take.
  • The five export files are kept for provenance in exports/: wos_extraA_2026-11-21.xls, wos_s4_2026-11-21.xls, wos_s5_2026-11-21.xls, wos_s5_p2_2026-11-21.xls, wos_extraC_2026-11-21.xls. They were regenerated from the live WoS result sets on 21 November 2026; never hand-edit them.
  • Screening basis: title + abstract + keywords of every exported record. The full text of the four exports was additionally searched for the terms queue, queing, waiting time, backlog, service rate, arrival rate, backlogged; the only match is recorded in the table (S5 record 50, also Extra C record 5).

6. Result

Zero records retained. The four WoS sets echo the Scopus result: telecom, transport, healthcare and production-inventory queueing, plus WEAP-type water-supply scenario studies in which “unmet demand” is a modelled deficit, not a queue state. Two institutional echoes worth one sentence each in P1’s prior-art discussion, not gap-changing:

  1. Water-rights allocation is described as operating “according to a queuing system” of priorities — Extra A records 5 (annual-review water-markets paper) and 6 (Tunisia). This is an institutional priority rule, not a stochastic queue state with indicators.
  2. Healthcare emergency-care capacity queueing (S5 record 50 / Extra C record 5) is the same service-capacity machinery we propose, applied to patients — supporting the maturity of queue methods, not drought prior art.
