# P02 — Novelty-strengthening investigation (25 November 2026)

**Status:** exploratory Phase-B support for P01; not a new systematic review and not a replacement for the frozen Phase-A sentence.

## Purpose

Apply the attached *Scientific Novelty Discovery Agent* workflow to the existing queue–drought project, using the repository's completed Phase-A audit as the evidence base. The investigation asks which defensible extension would most improve P01 and prepare P02 without inventing priority or overstating the frozen gap.

## Main finding

The strongest organizing direction is an **identifiability-first, conservation-constrained deficit-state model**:

1. treat physical storage and unmet-demand backlog as distinct states coupled by the served-water flux;
2. enforce an explicit demand-conservation ledger;
3. test whether demand, service and structural parameters are identifiable from available observations;
4. derive queue indicators only after that gate;
5. validate against exact queue references and pre-specified held-out drought tests.

This is not a claim that coupled drought state spaces are new. Acosta et al. (2026, SSRN preprint, DOI `10.2139/ssrn.6835758`) already propose a broad coupled human–water state-space framework with unmet accessible demand. Zhao et al. (2018, *Journal of Hydrology*, DOI `10.1016/j.jhydrol.2018.05.037`) already model non-stationary supply and demand for reservoir reliability. Neither record contains the full four-part queue-specific combination in the frozen sentence.

## Recommended sequence

1. **P01 now:** conservation ledger, corrected indicator contract, identification gate, pre-specified test table and reproducible figures.
2. **P02 after Gate B:** time-varying recovery distributions, parameter-identification experiments, zero-flow semantics, dependence-aware uncertainty and held-out validation.
3. **Do not claim:** a broad new drought state-space theory, ML-for-queues, time-varying queueing, or superiority before the pre-specified tests are met.
