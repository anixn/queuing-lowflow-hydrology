# 00 — Research brief

| Field | Description |
|---|---|
| Working topic | Defensible novelty strengthening for the queue–drought papers |
| Scientific domain | Stochastic hydrology, drought science, queueing theory, hydrological state estimation |
| Research objective | Identify a high-impact, falsifiable extension that improves P01 and prepares P02 while preserving the frozen 21 November 2026 gap sentence |
| Context | India-focused CAMELS-IND/IMD/CMIP6 programme; P01 targets WRR, P02 targets HESS; P01 must remain first |
| Candidate data | CAMELS-IND forcings and streamflow, catchment attributes, IMD climate, crop/calendar statistics, reservoir/soil/groundwater observations where available, drought-event catalogue, future bias-corrected CMIP6 only |
| Candidate methods | Finite-state CTMC, exact stationary/Floquet/DES references, constrained rate estimation, conservation-constrained state inference, time-dependent first-passage equations, blocked validation |
| Expected contribution | A queue-specific deficit-state framework whose indicators are physically accounted for, identifiable where possible, and tested against exact references and pre-specified drought baselines |
| Constraints | Frozen novelty sentence; P01 before P02; no raw CMIP6 in published numbers; no pilot number as a finding; no unannounced assumptions; 42-test baseline must stay green |
| Unknowns | Zero-flow semantics for gauge 4026; regulation status; canal/crop records; independent storage/impact observations; whether structural parameters are identifiable; full prior-art coverage for every candidate |

## Decision rule

A candidate is retained only if it survives an adversarial search, has a falsification test, is feasible with available or explicitly identified data, and adds knowledge beyond renaming an existing index or applying a standard algorithm to a new place.
