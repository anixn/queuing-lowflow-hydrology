# 01 — Domain ontology

## Core concepts

- Drought as anomaly: SPI, SPEI, SSI, low-flow frequency and duration.
- Drought as state: storage, accessible water, demand, deficit, backlog.
- Queue mechanics: arrivals, service, servers, capacity, blocking, balking, reneging, feedback, busy period, first passage.
- Conservation: served flux, abandoned flux, backlog stock, backlog exposure, storage balance.
- Identification: structural identifiability, observational equivalence, profile likelihood, state estimation, data assimilation.
- Validation: exact stationary product form, Floquet periodic solution, MMPP, Gillespie DES, held-out years/basins/events.

## Terminology traps

- French *queue de distribution* means a distribution tail, not queueing theory.
- Institutional water-rights “queuing” is priority allocation, not a stochastic queue state.
- A reservoir deficit is not automatically an unmet-demand backlog.
- A coupled state-space model is not automatically a queue model.
- Exact forward-solver validation is not empirical parameter identification.
