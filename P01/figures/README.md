# P01 manuscript figures

All figures are generated by `../../src/P01/make_figures.py` from the shared queue engine and the 44-case sensitivity CSV. Rendering uses matplotlib in the base Python environment; the underlying data use NumPy only.

```powershell
python src/P01/box1_sensitivity.py
python src/P01/make_figures.py
```

Each figure is supplied as PNG and editable SVG. All numerical content is **synthetic; illustrative, under the stated assumptions**.

## Figure 1 — Drought–queue mapping and conservation ledger

`figure1_mapping.png` / `figure1_mapping.svg`

Demand and supply generate λ(t) and μ(t), which drive a finite-capacity backlog Q(t). Storage X(t) is a distinct state coupled through the served-water flux. Indicators feed verification and held-out validation.

## Figure 2 — Box 1 averaging error

`figure2_box1.png` / `figure2_box1.svg`

Stationary and seasonal queues share the same mean rates. After a one-year spin-up, the seasonal run peaks at E[Q] = 2.130 claims and Pr(Q ≥ 6) = 0.0733, versus 0.916 claims and 0.0043 for the stationary run.

## Figure 3 — Sensitivity of the averaging effect

`figure3_sensitivity.png` / `figure3_sensitivity.svg`

Across 44 declared cases, the seasonal/stationary peak-backlog ratio ranges from 1.20 to 5.33 and the critical-probability ratio from 2.06 to 92.9. Every case preserves the direction of the effect.
